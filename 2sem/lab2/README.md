# Project Setup

This lab reorganizes the code from **Lab 1** into a small reusable library and a separate example project.

## Features

- Fibonacci generator
- Iterator with timeout support

## Installation

Clone the repository:

```bash
git clone <repo_url>
cd example
npm install
node index.js
```

## Run Example

```bash
node index.js
```
